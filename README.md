# MediCitas

Sistema web para la gestión de citas médicas. PHP, HTML, CSS y MySQL en XAMPP.

## Cómo abrirlo

1. Copia esta carpeta a `C:\xampp\htdocs\medicitas`.
2. Enciende Apache y MySQL en XAMPP.
3. En phpMyAdmin importa `medicitas.sql`.
4. Abre `http://localhost/medicitas`.

## Cuentas de prueba

Contraseña de los médicos: `12345678`

Ejemplo de médico: `laura.cifuentes@medicitas.com`

El panel del equipo pide el código `BARZAL`. El correo de un administrativo debe terminar en `@medicitas.com`.
